# 📦 PMS - Inventory Manager

A full-stack **Inventory Management System** built using **Java, Spring Boot, ReactJS, MySQL, and Microservices Architecture**.  
The application helps businesses manage products, inventory, categories, users, and stock operations through secure RESTful APIs.

---

## 🚀 Features

### 🔐 Authentication & Security
- User registration and login
- JWT-based authentication
- Refresh Token implementation
- Role-based authorization
- Google OAuth2 login integration

### 📦 Product Management
- Create, update, delete, and view products
- Product categorization
- Search and filter products
- Manage product details and pricing

### 📊 Inventory Management
- Track available stock
- Update inventory quantities
- Monitor stock levels
- Prevent inventory inconsistencies

### 🏷️ Category Management
- Add and manage product categories
- Assign products to categories

### 🔄 Microservices Architecture
The application follows a distributed microservices architecture:

- User Service
- Product Service
- Inventory Service
- Order Service
- API Gateway
- Service Discovery (Eureka Server)

Each service is independently developed and communicates using REST APIs.
